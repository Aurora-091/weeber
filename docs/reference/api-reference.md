# API reference

Every HTTP route the backend serves, grouped by the router that mounts it. Generated by reading
`packages/api/src/index.ts` and each mounted router — if you add a route, add it here.

All routes live under the `/api` base path (`index.ts` → `new Hono().basePath('api')`). The mount table:

| Mount | Router file | Auth |
|---|---|---|
| `/api/voice/*` | `voice/routes.ts` | admin key, except the signature-verified telephony webhooks |
| `/api/voice/*` (admin console) | `voice/admin-routes.ts` | admin session **and** admin key |
| `/api/workflows/*` | `voice/workflows/admin-routes.ts` | admin session **and** admin key |
| `/api/app/*` | `app/routes.ts` | Supabase user session (`requireUserSession`), then `requireUserOrg` |
| `/api/public/*` | `app/public-routes.ts` | none (deliberately zero-auth) |
| `/api/leads/*` | `voice/leads/ingest.ts` | per-org lead API key (`Authorization: Bearer wlk_…` or `X-Api-Key`) |
| `/api/integrations/shopify/*` | `integrations/shopify/routes.ts` | `X-Weeber-Secret` (see [contract.md](./contract.md)) |

The Twilio Media Stream WebSocket (`/api/voice/stream`) is **not** a Hono route — it is handled natively
in `server.ts` via `voice/ws-route.ts`.

## Telephony webhooks (`voice/routes.ts`)

Signature-verified, never admin-key gated — the carrier is the caller.

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/voice/incoming` | `requireTwilioSignature` | Twilio inbound webhook — returns TwiML that opens the media stream |
| POST | `/api/voice/incoming/plivo` | `requirePlivoSignature` | Plivo inbound webhook — returns Plivo XML |
| GET | `/api/voice/transfer-xml/plivo` | none | XML served to Plivo when a call is transferred to a human |
| POST | `/api/voice/status-callback` | `requireTwilioSignature` | Call lifecycle status callback — finalizes the call, feeds the workflow engine |
| POST | `/api/voice/amd-status-callback` | `requireTwilioSignature` | Answering-machine-detection result callback |
| POST | `/api/voice/recording-status` | `requireTwilioSignature` | Recording-ready callback |
