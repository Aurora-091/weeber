# Changelog — September 2026

## 2026-09-05 — Cartesia must not wait three seconds to speak (ADR-125)

Appointment-setter dead air (LLM text, zero TTS bytes) after ADR-124. Cartesia's websocket
defaulted `max_buffer_delay_ms` to 3000 when omitted. We now send 180ms on every continuation
and `flush: true` with `continue: false` on `endTurn`. TTS socket reuse across turns is still
Phase C1 (ADR-083 idle timeout).

## 2026-09-05 — Empty hangUp is not "didn't catch that" (ADR-124)

Two insurance test calls after ADR-123 conversed, then failed in different ways. Post-sale welcome
called `hangUp` with no closing line (documents never arrived) and the empty-turn path still spoke
the hearing apology. Skip `FALLBACK_REPLY` when `hangUp` or `transferToHuman` already ran this
turn. Appointment-setter dead air (LLM text, zero TTS bytes) is not this fix.

## 2026-09-05 — Twilio AMD hijacked a live call (ADR-123)

A test call that was conversing (two turns, Cartesia) was cut off by a different voice saying
sorry to have missed the person. `POST /api/voice/amd-status-callback` had classified the live
human as a machine and Twilio `<Say>` took the stream. AMD now defaults on for US NANP only;
dashboard test calls pass `amd: false`; a `machine_*` result is ignored once the caller has spoken.

## 2026-09-05 — First-token timeout vs tools (ADR-122)

Live call logs looked like a hearing problem. They were not. STT/TTS were fine; insurance turns called
`crmSync` with no CRM connected, the 2.5s first-token bound aborted the model mid-tool, and the agent
spoke "Sorry, I didn't quite catch that." Fix: defer that abort when a tool started this turn; omit
`crmSync` unless the org has connected credentials; rewrite insurance runtime personas tag-free
(ADR-065). Re-seed `agentTemplates` on deploy for the new persona bytes; an editor-pasted persona is
unchanged until saved again.
