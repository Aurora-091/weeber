# Competitor changelog scan — Bolna, Retell, Bland (2026)

**Date:** 2026-07-17. Pulled directly from each platform's public changelog (Bolna's monthly docs pages, Retell's changelog, Bland's "What we shipped" feed) — not secondhand summaries. Scope: what they've actually shipped in 2026, organized by theme, with a read on what's relevant to Weeber's own roadmap.

## TL;DR — what matters most for Weeber

1. **Every competitor has converged on "agent building via AI, not manual prompt engineering."** Bolna shipped Studio (brief → full agent) and Bolna Skills (Claude Code/Cursor/Codex integration) in June. Bland shipped Norm (conversational pathway builder) back in March and keeps extending it (custom skills, auto-fix via Triage). This is now table stakes, not a differentiator — worth checking Weeber's own onboarding flow against this bar.
2. **Live call intervention is now standard at the top of the market.** Retell shipped Live Call Monitoring (listen in, whisper, take over) in June. Bland's Alerts + Triage do the automated version of the same thing. Weeber doesn't have this yet — worth a look given Weeber's compliance-first positioning (a human being able to intervene mid-call is itself a compliance-friendly feature, not just an ops one).
3. **CRM sync is being built natively, not left to Zapier.** Retell shipped Built-in CRM (two-way Salesforce/HubSpot sync, auto contact creation) in June. Bland shipped Contact Memory Sync to the same two CRMs in July. Two of three competitors now treat this as core platform, not an integration afterthought.
4. **Multilingual is graduating from "a language dropdown" to real per-caller routing.** Retell's Granular Multilingual (May) and Bolna's per-language static messages (July) both auto-detect and switch mid-flow without menus. Directly comparable to Weeber's own Hindi/Hinglish work this month — good sign Weeber's instinct (real live-verified language handling, not a checkbox) matches where the market is actually going, not just where Weeber happens to be.
5. **Auto-failover across STT/LLM/TTS providers is now a baseline expectation, not a differentiator.** Retell already had transcription auto-failover (Feb) and per-call LLM/TTS fallback (Feb 2025). Weeber shipped its own cross-provider failover this session (recommendation #1 of the GTM report) — this closes a real gap, not a novel lead.
6. **Nobody in this scan has shipped Weeber's specific wedge (vertical, compliance-first, TCPA/DNC-baked-in for the Shopify/clinic SMB segment).** Retell and Bland are both going *up*-market (Enterprise-tagged features: SIP wizard, static IP, branded caller ID, RBAC) and *horizontal* (any use case via pathways/graphs). Bolna is leaning developer/open-source + India-telephony practical (region-based Indian number search, Vobiz telephony). None of the three are building a vertical-specific compliance/onboarding experience the way Weeber is — this gap is still open.

## Bolna AI — developer-first, India-practical, open-source posture

Best read: Bolna is building for technical teams who want a capable, honest, low-friction open-core platform — not chasing enterprise logos.

| Month | Shipped | Why it matters |
|---|---|---|
| July | GPT-5.6 family (3 tiers) + GPT-5.5 Pro; multilingual static messages (per-language pre-cached clips, zero LLM/TTS cost); webhook filtering by call status; router nodes (silent branching, no spoken turn) | Static per-language messages is a real, cheap latency trick — worth stealing the *idea* even if not the implementation: any deterministic line (greeting, disclosure) can be pre-cached per language, not just per provider. Weeber's own `literalGreetingTemplate` is the English-only version of this same idea. |
| June | Per-account concurrency limits (min/max floors for sub-accounts); **Soniox real-time transcriber** — single-stream multilingual + code-switching, no per-language mode-switching; typed variables + per-node tool scoping for graph agents; visual graph editor; pre-call webhooks (transfer + custom tools); **Studio** (brief → full agent, no prompt engineering); **Bolna Skills** (AI coding assistant integration, 20 skills) | Soniox is a real STT competitor to the ElevenLabs Scribe/Sarvam codemix stack Weeber just built out for Hindi/Hinglish — worth a quick eval if code-switching quality ever needs another option. Studio + Skills is the clearest "agent building via AI" data point in this scan. |
| April | Conversation rating/feedback (1-4 scale + notes); import custom functions from cURL; LLM reasoning surfaced in execution logs; **extraction confidence scores + typed validation** (email/timestamp/regex); multilingual agent support; region-based Indian phone number search; unified voice selector (search + gender filter + inline preview) |Extraction confidence scoring (route low-confidence results to human review) is a genuinely good idea for Weeber's `captureField` tool — currently binary captured/not-captured, no confidence signal. |

## Retell AI — enterprise velocity, "sound human not just correct"

Best read: Retell ships fast (biweekly cadence, explicit "launch weeks") and is aggressively going up-market — RBAC, SIP, PII redaction, branded caller ID, data retention controls all point at mid-market/enterprise buyers, not SMBs.

| Month | Shipped | Why it matters |
|---|---|---|
| June (launch week) | **Built-in CRM** (2-way Salesforce/HubSpot sync, returning-caller recognition); **Live Call Monitoring** (real-time transcript, sentiment/latency/interruption scoring, listen-in/whisper/take-over, auto-actions on a bad call); Custom Dashboards (per-team views); **Colloquial Model** (rewrites LLM output to sound less robotic, ~50ms overhead, one toggle); **Expressive Mode** (auto + manual emotion tags, reads caller's pace/pitch as a signal) | Colloquial Model is the most interesting single feature in this whole scan — a post-processing layer between LLM and TTS that fixes "I apologize for the inconvenience"-style stiffness without touching the prompt or the model. Directly applicable to Weeber's own agent quality bar. |
| May | Agent Versioning 2.0 (drafts, staging/prod environment tags, one-click promotion); **Granular Multilingual** (hand-picked language sets, auto-detect, no menus); iOS/Android call-screening detection + auto-response; custom voicemail handling (hang up / pre-recorded / generated-on-the-fly); Voice Orb shareable demo link | Call-screening detection is a real, non-obvious outbound-calling problem (more people screen calls now) that Weeber hasn't addressed at all — worth flagging for the outbound cart-recovery/COD-confirmation use cases specifically. |
| March | ChatGPT app integration (build/deploy/test/monitor a Retell agent from inside ChatGPT); **dynamic voice speed** (matches caller's pace, responds to "slow down"/"talk faster"); A/B testing (split traffic by %, compare prompts/voices); ElevenLabs v3 voices; PCAP downloads for call debugging | Dynamic voice speed is a real accessibility/quality win (elderly/hearing-impaired callers, non-native speakers) that's cheap to reason about even if not cheap to build — worth a design note for later. |
| Feb | Safety guardrails (jailbreak/harmful-content blocking, hard stop not soft warning); global node return paths (resume conversation after a detour); webhook/function test tools (dry-run before going live); **audio transcription auto-failover** (Deepgram↔Azure, mid-call, no dropped audio); billing line-item separation (TTS vs voice engine vs LLM vs telephony) | STT auto-failover mid-call (not just at connect time) is more aggressive than what Weeber shipped this session (Weeber's failover is per-connection-attempt, not a live swap mid-utterance) — worth noting as a "how far does this need to go" reference point. |

## Bland AI — "Norm" as the platform, enterprise pathway tooling

Best read: Bland has fully bet on Norm (their AI pathway-building/fixing assistant) as the platform's spine — most 2026 releases either extend what Norm can do or extend the pathway canvas Norm operates on. Also clearly enterprise-tilted (SIP wizard, static IP equivalents, GitHub-synced pathway version control).

| Month | Shipped | Why it matters |
|---|---|---|
| July | Contact Memory Sync to HubSpot/Salesforce (auto, no per-call tool config) — same category as Retell's Built-in CRM, shipped ~3 weeks later | Confirms native CRM sync is now a two-of-three-competitor baseline, not a nice-to-have. |
| May | Evals (LLM judges grading audio/tone/hallucination/resolution per call, custom rubrics); Norm custom skills (org-scoped, slash-command triggered); **iMessage as a third channel** (branded contact, same pathways/persona/memory as voice+SMS) | iMessage-as-a-channel is a genuinely different move — nobody else in this scan is doing omnichannel-with-shared-persona-memory. Low priority for Weeber's current Shopify/clinic scope but worth knowing exists. |
| April | Alerts (built-in + custom plain-language conditions, e.g. "caller asked for a manager"); Analytics dashboards rebuilt around AI-generated custom panels; GitHub integration for pathway versions (structured `source/` dir, diff preview before import); **Triage** (flag a bad call → Norm investigates, fixes the pathway, verifies via simulation); Agent-to-Agent Testing (AI caller simulates real conversations against scenarios) | Triage (auto-diagnose-and-fix from a flagged bad call) is the most aggressive "AI operates the platform for you" feature in this scan — a real signal of where agent-building UX is heading generally. |
| March | Tools directly on pathway nodes (webhook/code/custom-tool/tool-chain, inline instead of separate nodes) | Mirrors Bolna's per-node tool scoping (June) — both platforms converged on "narrow which tools are even visible to the LLM at a given conversation step," same problem Weeber's `enabledTools` (call-wide, not per-node) doesn't yet solve at the node/state level. Only relevant if/when Weeber builds a graph/flow editor (tracked separately in the workflow-canvas-v2 research doc). |
